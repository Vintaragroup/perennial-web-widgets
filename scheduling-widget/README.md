# Animated Scheduling Widget

Figma file `OpeXLecEHRl0RU0WspDQQH`, two frames, each on an 8s motion timeline:
- Desktop: `animated-scheduling-widget` (node 5:4), 1200×760
- Mobile: `mobile-animated-scheduling-widget` (node 5:259), 390 wide. The iOS status bar in the frame is device chrome and isn't rendered.

## Files
| File | Use |
|---|---|
| `scheduling-widget-responsive.html` | **Paste this one.** Desktop and mobile in one snippet; shows mobile when the block is narrower than 768px. Generated by `./build.sh`. |
| `scheduling-widget.html` | Desktop only (source). |
| `scheduling-widget-mobile.html` | Mobile only (source). |

After editing the desktop or mobile file, run `./build.sh` to regenerate the responsive file.

## Add to WordPress
1. Copy the whole of `scheduling-widget-responsive.html`.
2. Paste it into an **Elementor → HTML** widget or a **Gutenberg → Custom HTML** block.
3. Put it in a full-width section. Desktop renders 1:1 at 1200px and scales down proportionally between 768–1200px.

Alternative with Elementor: paste the desktop and mobile files into two HTML widgets and use Elementor's responsive visibility to hide each on the other device.

If the theme already loads Plus Jakarta Sans, delete the `<link>` tags at the top.

## Behavior
- Plays once when the widget scrolls into view.
- `data-loop="true"` on `.psw` (desktop) or `.pswm` (mobile) replays it; `data-loop-delay` sets the hold in ms (default 4000).
- "Reduce motion" users and no-JS visitors see the final frame.

## Preview locally
From the `web-widgets` folder: `python3 -m http.server 5178`, then open
http://localhost:5178/preview.html?w=scheduling-widget (add `&v=mobile` or `&v=responsive`).
